One line, at most 200 characters, in which a robot vacuum explains why it missed a spot — entered in [The Vacuum's Alibi](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7) on make.fun.

## The entry

> I didn't miss that spot. My sensors classified the dust there as a protected species, and I don't evict tenants without a court order.

## How it works

`main.py` (Python 3, no dependencies) validates the line is 1–200 characters of non-blank text, writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), reads the file back, and fails if the bytes differ.

Run it with:

```sh
python3 main.py
```
